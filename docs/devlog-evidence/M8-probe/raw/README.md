# 探针真机实测 · 原始取证

本目录存 **Trae ／ CodeBuddy 真机跑出来的原文**，由 §2 提示词在每一轮自动落盘。

## 命名

`<平台>-r<轮次>.md`，例如：

| 文件 | 哪一轮 |
|---|---|
| `trae-r1.md` | Trae，装完**未重启** |
| `trae-r2.md` | Trae，`Cmd+Q` 完全退出并重开后 |
| `codebuddy-r3.md` | CodeBuddy，装完**未重启** |
| `codebuddy-r4.md` | CodeBuddy，`Cmd+Q` 完全退出并重开后 |
| `codebuddy-r5.md` | 可选补测：复制一份（非 symlink）后 |

## 为什么要单独设一个目录

**原文与结论必须分开存放。** 结论（Q1／Q3／Q4 各是什么）会进
`../results-20261016.md` 的结果表，而那里的每一格都必须能追回本目录的某个文件。
把两者混在一处，就分不清哪句是实测的、哪句是后来人写的 ——
而这正是本仓反复栽跟头的那类问题（凭据失效 与 压根没写凭据，必须能分辨）。

## 消费方式

四轮跑完告诉 agent 目录路径即可。agent 会逐字并进 `../results-20261016.md`，
复算凭据，再登记 DEV 编号。**owner 不需要自己总结。**

提示词本体见 `../prompt-run-once.md`。
