## §4 什么时候会**多**跑一轮（可选补测）

如果轮次 3 或 4 的结果是「不认 symlink」，还要排除另一种可能：
**是它不跟随 symlink，还是它压根没在那个位置找。**

由 owner 在终端跑：

```bash
cp -R ~/.agents/skills/openvibe-probe ~/.codebuddy/skills/openvibe-probe-copy
```

（`codebuddy` 换成不认 symlink 的那个平台；`-copy` 后缀防止与 symlink 那份撞名。）

然后**完全退出并重开该平台**，把 §2 的提示词再贴一轮，这次用：
```
【平台】codebuddy
【轮次】5
```
（Trae 同理则用 `trae` / `5`。）

**判定**：认得 ⇒ 是 symlink 的问题；**仍不认得 ⇒ 是位置或加载机制的问题** ——

## §6 这三问答不出来会导致什么（说明为什么要跑）

| 问 | 卡住的东西 | 卡不住会怎样 |
|---|---|---|
| **Q1** 加载时机 | M8 安装指引要不要写「装完请重启」 | 用户装完 skill 却发现 agent 不认得，**且没有任何提示告诉他该重启** |
