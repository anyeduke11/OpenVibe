| -------- | --------- | ---------------------------------------- |
| 开关     | `:188`    | 台账**没有**开关，无条件记录             |
| 关掉之后 | `:189`    | 关遥测对它**零影响**，照样记             |

### 可拍性：⚠️ **半张能拍，半张不能**

| 判定物                         | 能不能现在拍                    | 原因                                                          |
| ------------------------------ | ------------------------------- | ------------------------------------------------------------- |
| 1/2 README `README.md:182-203` | ✅ 能                           | 纯文本，在版本库里，无前置阻塞。文件名 `j-readme-182-203.png` |
| 2/2 设置页两节                 | ❌ **不能，现在拍到的是中间态** | 见下                                                          |

**设置页为什么现在不能拍**（2026-10-17 实测）：

1. **三节并存**。工作树 `apps/web/src/pages/SettingsPage.tsx` 同时挂了三节 ——
   `TelemetrySection`（`:58`）、`LocalLedgerSection`（`:60`）、旧 `LedgerSection`（`:71`）。
   owner 已裁「**删旧 `LedgerSection`、只留 `LocalLedgerSection`**」（见 `local-event-ledger.md` ⚠️l 段），
   现在拍到的是**裁之前的中间态**，与目标态不符 —— 拍下来的图会同时被读成「已裁」和「未裁」。
2. **替代者尚未入库**。`LocalLedgerSection.tsx` 仍是未跟踪文件（`git cat-file -e HEAD:…` → 不存在），
   在 HEAD 里设置页**只有 `TelemetrySection` 一节**（`:26`），连「两节并排」都不成立。
3. 删旧节要动 `SettingsSections.tsx`，属并行活跃会话的改动面，本会话不抢写。

⇒ **设置页那半张的前置条件**：`apps/web` 交叠解除 → 删旧 `LedgerSection` → `LocalLedgerSection` 连同 5 处依赖全部入库
（`i18n/lane-system`、`components/ui/icons`、`SettingsSections` 的 `Section` 导出、`ui/styles` 的 `proseCls`／`skelCls`）
→ 才可拍。前四项满足前拍出来的图必是错的，不值得拍。

### 设置页怎么拍（前置满足后）

1. 设置页滚到台账节与遥测节，两节**同屏**（判据问的是「能否讲清本机≠遥测」，两节必须可比）。
2. 文件名：`j-settings-ledger-vs-telemetry.png`。
3. 画面要能读出：两节各有独立正文、**台账节挂「不出网」chip**、遥测节讲的是可关可发的另一件事。
4. ⚠️ 旧 `LedgerSection` 的文案写着「append-only · 可清空 · 本机可复算 · **不出网**」与
   「与匿名遥测正交：本层永远在，关掉遥测它照样记账」—— 但它读的是 `/api/telemetry/events` → `telemetry_events` 表，
   **受遥测开关控制、带 `sent_at`、会被发出**。界面写着「不出网」，数据其实会出网。
   那一节已裁定删除，**若拍到它还在，说明前置没满足，别签收**。
