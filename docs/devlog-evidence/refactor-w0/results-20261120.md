## 二、机制验证（合成样本，15 腿）

探针：`drift-shape-probe.mjs`，输入 = `tests/golden/G1/files/` 的**真实冻结字节**（非手写夹具），分类器 = `diffSections`（RQ4 纯函数，`packages/core/src/inject/section-diff.ts`）。

| 场景                 | 真实等价场景     | CLAUDE.md       | AGENTS.md       | TERMS.md               | 可归因 |
| -------------------- | ---------------- | --------------- | --------------- | ---------------------- | ------ |
| S1 受管块内改 1 行   | 用户手改过时正文 | managed ✅      | managed ✅      | 自由区（无壳）✅       | ✅     |
| S2 自由区纯新增      | 用户加自己的约定 | free ✅         | free ✅         | free ✅                | ✅     |
| S3a 整文件重写保留壳 | AI 全量重写      | managed ✅      | managed ✅      | free ✅                | ✅     |
| S3b 用户去壳         | 删标记行         | managed+free ✅ | managed+free ✅ | **不适用（本就无壳）** | 14/15  |
| S4 并存（改+加）     | 最常见形态       | managed+free ✅ | managed+free ✅ | free ✅                | ✅     |

**机制结论**：分类器对全部可适用形态都能给出「受管块 / 块外自由区 + 两侧行数」的段级归因——**统计工具链就绪**。S3b 对 TERMS.md 的「不适用」是场景对无壳文件无操作的如实记录，不是缺陷。

## 三、盲区实证（本探针的最有价值发现）

`TERMS.md` 的冻结字节（`tests/golden/G1/files/TERMS.md`，12 行）**不含任何受管标记**。推论链：

1. 无壳文件的任何漂移，`diffSections` 只能按「块外自由区」报告——**没有段级能力，也没有「以包为准」的合法覆盖面**（自由区差异是用户的权利，处置永远倒向保留本地）。
2. 这正是分析文 §4.5 D4-4-c（段级受管标记进契约 = D32）要解决的问题的**实证形态**：不是「要不要更精细」，而是**部分产物文件根本没有受 D32 保护**。
3. 若 D32 落地（标记进契约 + TERMS.md 套壳），TERMS.md 的漂移将从「文件级无法归因」变为「段级可归因」——这一条可以直接写进 D32 的签字说明。

**复算**：`grep -c "openvibe:" tests/golden/G1/files/TERMS.md`（= 0；CLAUDE.md/AGENTS.md 各 2 行标记）。

## 四、真实样本到来时的统计协议（模板已就绪）

**触发条件**：任一项目执行 `openvibe sync` 注入成功（`injections` 表出现首行）。

**统计动作**（届时复跑）：

1. 对每个注入项目跑 `openvibe diff <dir>`（或探针同款 `diffSections` 直调），收集每受管文件的 `regions` 输出；
2. 按 S1–S4 四形态归类每次真实漂移（判据：`managedChanged`/`freeChanged`/`missing` 组合）；
3. 报告三件事：**形态分布**（四形态占比）、**归因率**（有壳文件的段级可归因比例）、**无壳文件清单**（D32 落地前的盲区面）；
4. 样本门槛：≥2 个真实项目、观察 ≥2 周（与 D15 观察窗同批采集，不另起窗口）。
